## Intent

Give sshtool a project map, entered at `map.md`, describing the system as it exists today: connection and hops, authentication, sessions and reconnect, forwarding, config resolution, key install, platforms. It needs a security node recording what each hop may and may not reach — notably that only the destination may open agent channels — and the known gap that host keys are not verified. Built node by node with the user, from the code and the archived changes.
